AKSense™ · AKFlow™ — сайт aksense.org (EN), готовый к деплою
============================================================

Статика, без сборки. Разворачивание:
  1. Распаковать содержимое в корень домена (public_html / www).
  2. index.html — на корне. Включить HTTPS.
  3. ВНЕШНИХ ЗАВИСИМОСТЕЙ НЕТ — шрифт Montserrat встроен локально
     (assets_Beige/fonts/), обращений к сторонним CDN нет.

Форма заявки (#order):
  Шлёт на e-mail из js/config.js (window.FORM_EMAIL = info@aksense.org)
  через FormSubmit.co. При ПЕРВОЙ отправке FormSubmit пришлёт на этот
  ящик письмо со ссылкой Activate — по ней надо один раз перейти
  (проверить и «Спам»), иначе заявки не приходят.

Оптимизация (относительно исходника):
  - Видео пережаты в 1280p H.264 CRF30 без аудио (~41 МБ → ~1.5 МБ).
  - Фоновые PNG сконвертированы в JPG q80 (~23 МБ → ~2.3 МБ).
  - Montserrat локализован (latin + latin-ext, woff2) вместо Google CDN.
    На EN-странице реально грузится ~250 КБ латиницы; latin-ext лежит
    в бандле и подтягивается только при появлении акцентированных букв
    (unicode-range), рантайм-штрафа нет.
  - В бандл включены ТОЛЬКО реально подключённые файлы.

Заглушки, которые надо заполнить перед продом:
  - Каталоги в секции #blog: <a href="#" download> → реальные PDF.
  - LinkedIn-ссылки (href="#").
